# Quaternion rotation

Euler angles are three knobs. A quaternion is one rotation.

Show a rotation I can see. Compare Euler with a quaternion so the difference is visible, not just named.

Implemented while studying Chapter 2.7 (Quaternions) and 2.2 (Rotations) of Eric Lengyel, *Foundations of Game Engine Development, Volume 1: Mathematics*. Implementation and visualization are my own.
